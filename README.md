# E-Commerce Sales Analysis

## 📌 Project Overview

This project analyzes e-commerce sales data to identify sales trends,
profit performance, category performance, regional performance, 
payment mode performance, and product performance.

The project uses Python, SQL,  and Power BI for data cleaning,
analysis, visualization, and dashboard creation.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- SQL / MySQL
- Power BI
- GitHub
